# ETS2OMSI V2.2 MATERIAL + PHYSICS — SCS-only AI car converter

Converts package-local ETS2 traffic-car exterior assets from one selected `.scs` into minimal OMSI 2 `.ovh` AI vehicles. ETS2 installation, base/DLC archives and Blender are not required by the normal workflow.

V2.1 is a golden-reference correctness update based on a known-working OMSI AI vehicle layout: corrected O3D axes, wheel-contact ground calibration, separate animated wheel O3Ds, correct OMSI AI_Cars relative paths, deterministic PIT/MAT/TOBJ texture resolution, and post-export orientation/texture/ground validation.

See `README_TR.md` and `GOLDEN_REFERENCE_NOTES_TR.md` for details.
