ETS2OMSI V2.2 Material + Physics helper tools

ConverterPIX
- Used internally for PMD/PMG -> PIM/PIT decoding.
- V2 attempts to download it automatically on first 3D preview/conversion.
- setup_converter_pix.ps1 remains as a manual fallback.

SCS archive helper
- ZIP-based traffic .scs packages need no helper.
- HashFS .scs packages may require setup_scs_packer.ps1 or another compatible helper.

ETS2 itself is not required.
